# Leaders Like Me

A search tool for teachers and students to find exemplars who aren't straight white cisgender men: scientists, artists, activists and more.

## Run it

Double-click `index.html`. There's no build step and nothing to install.

## Files

| File | What it is |
| --- | --- |
| `index.html` | Page shell, nav bars, background shapes |
| `styles.css` | Visual design, taken from the mockups (`Home.png`, `Log in.png`, `Profile.png`, `Search Results.png`) |
| `app.js` | Screens, search, accounts, saves |
| `data/tags.js` | The fixed list of identity and field tags |
| `data/collections.js` | The Collections: each one's title, months and the tags that decide who's in it. Add or edit collections here; they fill themselves from the repository. |
| `data/source/leaders.source.json` | **The repository: edit this.** 55 leaders from the 2021 survey and the leaders-like-me-api repo |
| `data/source/build.py` | Rebuilds the app's data and photos from the source file |
| `data/leaders.js`, `data/leaders.json` | Generated by the build script. Don't edit by hand. |
| `images/` | One photo per leader, max 480px, named `<id>.jpg` |
| `logo.svg`, `logo-dark.svg`, `favicon.svg` | Logo (white text for dark backgrounds, navy text for light ones) and the browser-tab icon. Regenerate with `data/source/make_logo.py`. |

## Screens

- **Home**: search, a daily spotlight, picks based on your likes, browse by identity or field, and a Surprise me button.
- **Explore** (replaces Browse and Search): everyone A–Z, with free-text search, identity and field filters (combined with AND), an A–Z letter row and sorting. Everyday words are mapped to tags, e.g. "Latina" finds `latine` and "autistic" finds `neurodivergent`. The URL updates as you search, so a teacher can share a link to a filtered view. Old `#/search` and `#/browse` links still work.
- **Collections**: ready-made sets for heritage and awareness months (each featured automatically during its month) and topics like Women in STEM. Defined in `data/collections.js`.
- **Leader profile**: tags, bio, Learn more, Share, Find similar, Suggest edit, save (heart).
- **Guess Who** (the **?** tab): a daily "Who am I?" puzzle with four photo cards: the answer plus three people who share the most tags with them. Clues are revealed one at a time, from hardest to easiest. There are three clues and no hints: a wrong pick crosses out that card and unlocks the next clue. After solving, students see the person's profile and can write what they have in common with them. Earlier days (up to 30) can be replayed. **Class mode** enlarges the text for projecting. Everyone gets the same mystery each day.
- **Badges**: 10 badges earned by how you play, never by which identities you uncover, and never taken away. Each badge shows the leaders it was earned with. Guests' badges stay on the device and move into an account at sign-up or log-in.
- **Saves**: everyone you tapped the heart on.
- **Your page** (the “You” link in the top bar): explains that everything is stored on this device, lists your saves, likes and badges, and has a “Clear everything on this device” button for shared computers.

## Updating the repository

1. Edit `data/source/leaders.source.json`. Tags must come from `data/tags.js`.
2. Set each person's `photo` to `{"repo": "file.jpg"}` (a file in the leaders-like-me-api repo's `public/images`), `{"commons": true}` (their Wikipedia/Wikidata photo, credited automatically), or `null` (shows initials).
3. If a photo crops badly in the circle, add `"imagePosition": "70% 20%"` (horizontal, vertical focus point).
4. Run `python3 data/source/build.py /path/to/leaders-like-me-api`.

After editing `app.js` or `styles.css`, run `python3 data/source/build.py --stamp-only`. It updates the version stamps in `index.html` so visitors get the new files instead of a stale cached copy.

`review` notes on an entry are for editors only and aren't shown in the app.

## Guess Who data

Only people with a `clues` list are included in the game (see the format in `data/leaders.js`). Give each person at least 3 first-person clues, hardest first. Each game uses the last three, so with four clues the hardest one is skipped. The day's person comes from a fixed shuffle of everyone with clues, so it's the same for every student on a given day.

## Suggestions

The **Suggest a leader** page (`#/suggest`) and the **Suggest edit** button on profiles both send answers straight to the original Google Form, so everything lands in the same Google Sheet. Suggested edits show up with "Suggested edit:" at the start of the Contribution column. The app's tags are mapped to the form's checkbox options, and anything more specific goes in the form's "Other" box. The form's field ids are in `SUGGEST_FORM` at the top of `app.js`. If you change the form's questions or options, update them there.

## No accounts (yet)

There are no logins. Saves, likes, badges and Guess Who progress are stored in the browser on each device (localStorage, keys starting with `llm.`). They don't sync between devices, and clearing browser data erases them. The app says this on the Saves page, on Your page, and the first time someone saves a leader.

When it's time for real accounts, the plan is a hosted login service such as Supabase, with Google and Microsoft school sign-in. Everything that reads or writes this data goes through the `Prefs` object in `app.js`, so that's the one place to connect it.
